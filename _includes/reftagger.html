{%- comment -%} Included from footer.html, NOT from body.html. GitBook navigates between pages by swapping the contents of .body-inner over XHR and re-running the inline scripts it finds there. This bootstrap used to live in body.html, inside that region, so every soft navigation re-ran `var refTagger = { settings: … }` and overwrote the fully initialised RefTagger object — including its tag() method — with a bare config object. References then stopped being tagged until a full page reload, and custom.js's retagReferences() could not help because refTagger.tag no longer existed. The footer sits outside .book, so it is not swapped. The guard below is a second line of defence in case this is ever included twice. {%- endcomment -%}
