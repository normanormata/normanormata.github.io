{%- comment -%} Class names deliberately avoid `search-results`, `has-results`, `no-results`, `search-results-title`, `search-results-list` and `search-results-item`. The vendored GitBook stylesheet targets those with very high specificity — e.g. `#book-search-results .search-results .has-results .search-results-item *` (1,3,0) forces `font-size: inherit` on every descendant, and `#book-search-results .search-results .search-results-title` forces uppercase, centred, 200-weight, 60%-opacity text. A separate `cc-` namespace means none of those rules match, so this UI can be styled normally. {%- endcomment -%}
